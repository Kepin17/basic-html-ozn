1 · Box Model

Setiap elemen HTML adalah kotak. Memahami lapisannya menjawab 80% pertanyaan "kenapa elemen ini ukurannya begini?".

Empat lapisan kotak

LapisanPropertiWarna di labFungsi
Contentwidth, height🟦 biruIsi elemen (teks, gambar)
Paddingpadding🟩 hijauJarak isi ke garis tepi (di dalam)
BorderbordergarisGaris tepi
Marginmargin🟧 oranyeJarak ke elemen lain (di luar)
Jebakan klasik: dengan box-sizing: content-box (bawaan), lebar total = width + padding + border. Ubah ke border-box dan lihat angka "lebar elemen" di bawah hasil: width jadi lebar total sebenarnya.

Tantangan

  1. Buat elemen selebar tepat 300px termasuk padding dan border. (Petunjuk: border-box.)
  2. Buat kotak berbentuk lingkaran: width sama dengan tinggi lalu border-radius: 50%. Di lab ini tinggi mengikuti isi, coba tambahkan baris height: 160px; di kode secara manual.
  3. Isi margin dengan nilai auto di kode: margin: 20px auto;. Apa yang terjadi pada posisi horizontal?

Rangkuman

padding: 10px 20px;          /* atas-bawah 10, kiri-kanan 20 */
padding: 5px 10px 15px 20px; /* atas, kanan, bawah, kiri (searah jarum jam) */
margin: 0 auto;              /* kotak berlebar tetap berada di tengah */
box-sizing: border-box;      /* width sudah termasuk padding + border */
