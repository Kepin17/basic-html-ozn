4 · Grid

Flexbox menata satu arah. Grid menata dua arah sekaligus: baris dan kolom, ideal untuk galeri dan tata letak halaman.

Konsep utama

PropertiFungsi
display: gridMengaktifkan grid pada induk
grid-template-columnsMenentukan jumlah dan lebar kolom
frSatuan "bagian dari sisa ruang". 1fr 2fr = kolom kedua dua kali lebih lebar
repeat(n, 1fr)Ulangi pola n kali
repeat(auto-fit, minmax(120px, 1fr))Kolom otomatis: sebanyak yang muat, minimal 120px. Responsif tanpa media query
grid-column: span 2Item memakai 2 kolom

Flexbox atau Grid?

  • Flexbox: satu baris atau satu kolom (navbar, tombol berjajar, isi kartu).
  • Grid: tata letak dua dimensi (galeri, dashboard, layout halaman).

Tantangan

  1. Buat galeri 4 kolom berjarak 12px.
  2. Pilih auto-fit minmax, lalu ubah lebar jendela browser. Perhatikan jumlah kolom menyesuaikan sendiri.
  3. Buat item pertama sebagai banner yang memanjang 4 kolom (span kolom = 4).
  4. Buat tata letak sidebar: pilih 1fr 2fr 1fr dan 3 item.
