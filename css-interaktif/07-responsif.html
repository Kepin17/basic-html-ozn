7 · Responsif

Satu halaman, banyak ukuran layar. Media query menerapkan aturan CSS hanya ketika kondisi tertentu terpenuhi, misalnya lebar layar.

Bentuk dasar

@media (max-width: 600px) {
  /* hanya berlaku bila lebar layar ≤ 600px */
  .grid { grid-template-columns: 1fr; }
}
  • max-width: berlaku saat layar sekecil atau lebih kecil dari nilai (desktop-first).
  • min-width: berlaku saat layar sebesar atau lebih besar (mobile-first).
  • Wajib ada <meta name="viewport" content="width=device-width, initial-scale=1"> di head, atau HP akan menampilkan versi "diperkecil" dari desktop.
Cara pakai lab: geser Lebar layar simulasi. Kotak hasil mengecil seperti layar HP. Ketika melewati breakpoint, tata letak berganti.

Tantangan

  1. Atur breakpoint di 768px dan geser lebar layar ke 767 lalu 769. Perhatikan perubahannya.
  2. Buat layar HP menampilkan 2 kolom (bukan 1), lalu navigasi menjadi tersusun ke bawah.
  3. Ubah kode menjadi mobile-first: tulis aturan HP dulu, lalu tambah @media (min-width: 700px) untuk desktop.
