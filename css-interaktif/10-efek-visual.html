10 · Bayangan & Filter

Memberi kedalaman dan suasana: bayangan kotak, bayangan teks, filter gambar, dan efek kaca buram.

Anatomi box-shadow

box-shadow: [inset] x  y  blur  spread  warna;
box-shadow: 0 8px 24px 0 rgba(0,0,0,.2);
NilaiArti
x, yGeser bayangan ke kanan / bawah (boleh negatif)
blurSeberapa kabur tepinya (0 = tajam)
spreadMemperbesar / memperkecil bayangan
insetBayangan di dalam kotak (efek tertekan)
koma ,Beberapa lapis bayangan sekaligus (mis. bayangan + cahaya)
Bayangan natural: offset-y kecil, blur besar, dan alpha rendah (0,1–0,25). Bayangan hitam pekat terlihat murahan.

Filter & backdrop-filter

FungsiEfek
blur(px)Mengaburkan

grayscale(n) / sepia(n)Hitam-putih / nuansa foto tua (0–1)
hue-rotate(deg)Memutar warna pada roda warna
saturate(n)Kepekatan warna
backdrop-filterFilter untuk apa yang ada di belakang elemen. Dasar efek glassmorphism

Lab B · Filter & efek kaca

Tantangan

  1. Buat kartu "melayang": 0 12px 30px alpha 0,18. Lalu hapus lalu bandingkan dengan bayangan 0 0 0 4px (spread saja, tanpa blur: terlihat seperti border).
  2. Buat tombol neon: aktifkan lapis cahaya (glow) dan beri warna hijau.
  3. Buat efek tertekan: aktifkan inset.
  4. Buat gambar tampak foto lama: sepia 0,8, contrast 1,2, brightness 0,9.
  5. Buat panel kaca: blur 8–12px dengan latar putih alpha 0,25.
Filter berat pada banyak elemen bisa membuat halaman lambat, terutama blur besar dan backdrop-filter.
