11 · Satuan & Variabel

Memilih satuan yang tepat membuat halaman lentur. Variabel CSS membuat satu perubahan bisa mengubah seluruh tema.

Satuan panjang

SatuanRelatif terhadapCocok untuk
pxPiksel layar (tetap)Garis tipis, bayangan, ukuran kecil
%Ukuran indukLebar kolom, gambar fleksibel
emfont-size elemen itu (atau induknya)Padding yang ikut ukuran huruf
remfont-size elemen html (akar)Ukuran huruf dan jarak yang konsisten
vw / vh1% lebar / tinggi layarHero setinggi layar, huruf judul besar
chLebar karakter "0"Lebar teks nyaman dibaca (max-width: 65ch)
Cara cepat: rem untuk huruf & jarak, % atau fr untuk lebar tata letak, px untuk detail halus.

Lab A · Satuan

Ubah ukuran huruf akar, ukuran huruf kontainer, dan lebar layar. Perhatikan satuan mana yang ikut berubah dan mana yang tidak.

Variabel CSS (custom properties)

:root { --utama: #2563eb; --radius: 12px; }   /* didefinisikan */
.btn { background: var(--utama);                /* dipakai */
       border-radius: var(--radius); }
.btn { padding: calc(var(--jarak) / 2); }       /* boleh dihitung */
  • Nama diawali --. Dibaca dengan var(--nama). Cadangan: var(--x, merah).
  • Berlaku di elemen tempat didefinisikan dan semua anaknya. Mendefinisikan ulang di elemen tertentu mengubah tema bagian itu saja, dasar mode gelap.

Lab B · Tema dengan variabel

Tantangan

  1. Di Lab A, ubah html { font-size } dari 16 ke 24px. Hanya satuan rem (dan em yang bergantung padanya) yang berubah.
  2. Perkecil lebar layar. Elemen vw ikut menyempit, px tidak.
  3. Di Lab B, ubah warna utama saja. Perhatikan tombol, garis atas kartu, dan lencana ikut berganti.
  4. Aktifkan mode gelap lalu buka CSS: hanya variabel yang ditimpa, aturan lain tidak disentuh.
