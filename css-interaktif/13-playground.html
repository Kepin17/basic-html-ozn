13 · Playground

Tidak ada kontrol di sini. Kamu yang menulis CSS. Pemeriksa otomatis di sebelah kanan mencentang tantangan yang sudah terpenuhi.

Misi

Ubah kartu polos di bawah menjadi kartu yang bagus. Ketik di tab CSS dan hasilnya langsung terlihat. Kamu juga bisa mengubah HTML-nya di tab HTML.

Tekan Tab di kotak kode untuk indentasi. Contoh awal: .kartu { background: white; }

Petunjuk bila macet

Lihat contoh jawaban 
.kartu {
  background: #ffffff;
  padding: 24px;
  border-radius: 14px;
  max-width: 360px;
  margin: 20px auto;
  box-shadow: 0 6px 20px rgba(0, 0, 0, 0.15);
}

h1 { color: #1d4ed8; }

.tombol {
  background: #2563eb;
  color: #fff;
  border: 0;
  padding: 10px 24px;
  border-radius: 999px;
  cursor: pointer;
}

.tombol:hover { background: #1e40af; }
