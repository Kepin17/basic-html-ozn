CSS Interaktif

Belajar CSS sambil melihat hasilnya langsung. Geser kontrol, atau ketik kode sendiri, dan lihat perubahan di layar saat itu juga.

Cara memakai

  1. Baca penjelasan singkat di tiap materi.
  2. Geser kontrol di panel kiri. Kode CSS ikut berubah dan hasilnya langsung tampil di kanan.
  3. Edit kode langsung di kotak CSS atau HTML. Hasilnya diperbarui saat kamu mengetik.
  4. Kerjakan tantangan di bawah tiap lab. Materi 13 punya pemeriksa otomatis.
Salin kode dengan tombol 📋 Salin, lalu tempel ke file .css milikmu sendiri.

Setelah CSS: JavaScript

Lanjut ke JavaScript Interaktif: variabel, logika, fungsi, array, DOM, event, dan proyek To-do.

Prasyarat

Sudah paham HTML dasar (heading, paragraf, list, tabel, form). Kalau belum, mulai dari HTML Interaktif.
