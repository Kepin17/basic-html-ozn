Instalasi & konfigurasi awal (sekali saja)

# 1. Pasang Git: https://git-scm.com/downloads  (Linux: sudo apt install git)
git --version

# 2. Perkenalkan dirimu (dipakai di setiap komit)
git config --global user.name  "Nama Kamu"
git config --global user.email "kamu@contoh.com"

# 3. Disarankan
git config --global init.defaultBranch main
git config --global core.editor "code --wait"     # editor pesan komit (VS Code)

# 4. Periksa
git config --list
Pakai email yang sama dengan akun GitHub-mu agar komit tercatat atas namamu. Jika ingin menyembunyikan email asli, GitHub menyediakan alamat noreply khusus di Settings → Emails.
