2 · Perintah Dasar

Lima perintah ini kamu pakai setiap hari: status, add, commit, diff, dan log.

PerintahFungsi
git initMenjadikan folder sebagai repositori Git
git statusApa yang berubah? Apa yang sudah di-stage? Jalankan sesering mungkin.
git add <file> / git add .Memasukkan perubahan ke staging area
git commit -m "pesan"Menyimpan staging menjadi komit permanen
git diff / git diff --stagedMelihat isi perubahan (belum di-stage / sudah di-stage)
git log --oneline --graphRiwayat ringkas dengan grafik

Siklus hidup sebuah berkas

Untracked
baru, belum dilacakadd →Stagedcommit →Committed (clean)edit →Modifiedadd →Staged
Cara pakai simulator: ketik perintah di terminal (atau klik chip perintah untuk mengisi), edit isi berkas di panel kanan, dan perhatikan berkas berpindah antar area. Panah ↑ mengulang perintah sebelumnya.

Praktik: komit pertamamu

Kapan sebaiknya commit?

  • Setelah satu perubahan logis selesai dan berjalan (satu fitur kecil, satu perbaikan bug).
  • Sebelum memulai sesuatu yang berisiko (refactor besar).
  • Bukan "sekali sehari di akhir hari": komit kecil dan sering lebih mudah ditinjau dan dibatalkan.
