3 · Branch & Merge

Branch memungkinkan kamu mengembangkan fitur tanpa mengganggu kode utama. Bayangkan jalur paralel yang nanti digabungkan kembali.

PerintahFungsi
git branchDaftar branch (tanda * = yang aktif)
git switch -c fitur-loginBuat branch baru dan langsung pindah (checkout -b untuk versi lama)
git switch mainPindah ke branch lain; berkas di folder ikut berubah
git merge fitur-loginGabungkan branch itu ke branch tempat kamu berada
git branch -d fitur-loginHapus branch yang sudah digabung

Dua jenis merge

JenisTerjadi saatHasil
Fast-forwardmain tidak berubah sejak branch dibuatPenunjuk main tinggal dimajukan, riwayat lurus
Merge commitKedua branch punya komit baru masing-masingDibuat komit baru dengan dua induk (lingkaran putih di grafik)

Penamaan branch yang rapi

AwalanContoh
fitur/ atau feat/fitur/login-google
fix/ atau bugfix/fix/tombol-tidak-bisa-diklik
docs/, chore/, refactor/docs/panduan-instalasi
Aturan emas: main harus selalu bisa dijalankan. Kerjakan di branch, gabungkan setelah selesai dan ditinjau.

Praktik: dua cabang, dua jenis merge

Repositori sudah punya satu komit di main. Perhatikan grafik komit berubah di setiap langkah.
