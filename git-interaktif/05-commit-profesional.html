5 · Commit yang Profesional

Riwayat Git adalah dokumentasi proyek. Pesan seperti "update" atau "fix" tidak membantu siapa pun, termasuk dirimu enam bulan lagi.

Anatomi pesan komit

tipe(lingkup): ringkasan singkat dalam bentuk perintah      ← subjek (≤ 50 karakter)
                                                              ← baris kosong
Penjelasan lebih panjang (opsional): MENGAPA perubahan ini     ← isi/body (≤ 72 karakter per baris)
diperlukan dan apa dampaknya, bukan sekadar apa yang diubah.

Closes #12                                                     ← footer: tautan issue
BREAKING CHANGE: ...                                           ← bila mengubah perilaku lama

Conventional Commits: tipe yang dipakai

TipeDipakai untukContoh
featFitur barufeat(cart): tambah tombol hapus item
fixPerbaikan bugfix(form): tolak email tanpa @
docsDokumentasi sajadocs: tambah cara instalasi di README
styleFormat/spasi (bukan logika, bukan CSS tampilan)style: rapikan indentasi
refactorMerapikan kode tanpa mengubah perilakurefactor(auth): pisahkan fungsi validasi
perfPeningkatan kinerjaperf: lazy-load gambar galeri
test, build, ci, choreTes, sistem build, otomasi, tugas lainchore: perbarui dependensi

Tanda ! menandai perubahan yang memutus kompatibilitas: feat(api)!: ganti format respons.

Penilai pesan komit

Tulis atau tempel pesan komit. Skor dan daftar aturan berubah langsung. Contoh bagus sudah diisi; coba rusak formatnya.

Prinsip komit yang baik

PrinsipPenjelasan
AtomikSatu komit = satu perubahan logis. Memperbaiki bug dan mengubah warna tombol → dua komit. Gunakan git add -p atau stage berkas terpisah.
Dapat dibangunSetiap komit membuat proyek tetap berjalan. Komit setengah jadi merusak git bisect dan review.
ImperatifSubjek melengkapi kalimat "Jika diterapkan, komit ini akan …": "tambah validasi", bukan "menambahkan"/"added".
Jelaskan mengapaDiff sudah memperlihatkan apa. Pesan menjelaskan alasan dan konteks.
Jangan commit sampahBerkas hasil build, node_modules, rahasia, dan console.log debug.

Sebelum, sesudah

❌ Buruk✅ Profesional
updatefeat(profil): tampilkan foto pengguna
fix bugfix(login): cegah submit ganda saat tombol diklik cepat
perbaikan tampilan dan juga menambahkan fitur caridua komit: style(header): rapikan jarak menu + feat(katalog): tambah pencarian live
Added new function.feat(utils): tambah fungsi format rupiah

Memperbaiki komit terakhir

git commit --amend -m "fix(form): tolak email tanpa @"   # ganti pesan komit terakhir
git add lupa.js && git commit --amend --no-edit           # tambah berkas yang tertinggal
# ⚠ amend menulis ulang riwayat: jangan lakukan pada komit yang sudah di-push ke branch bersama

Latihan: tulis ulang pesan buruk

Tiap pesan buruk di bawah harus kamu tulis ulang dengan format Conventional Commits (skor ≥ 90) dan menyebut topik yang diminta.
