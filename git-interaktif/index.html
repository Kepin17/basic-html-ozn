Git & GitHub Interaktif

Git adalah mesin waktu untuk kodemu; GitHub adalah tempat berkolaborasi. Di sini kamu berlatih di simulator Git yang berjalan langsung di browser: ketik perintah asli, lihat tiga area Git dan grafik komit berubah, dan selesaikan misi tanpa takut merusak apa pun.

Yang akan kamu kuasai

  • Alur kerja harian: add → commit → push.
  • Branch & merge, termasuk menyelesaikan konflik.
  • GitHub: repositori, pull request, review, dan kolaborasi tim.
  • Pesan komit profesional (Conventional Commits) dengan penilai otomatis.
  • Membatalkan kesalahan dengan aman: restore, reset, revert, stash.
Simulator mendukung perintah inti Git. Di komputermu perintahnya identik. Setelah latihan di sini, praktikkan dengan folder proyek sungguhan.

Alur kerja harian (GitHub Flow)

1. git switch -c fitur/x→2. edit kode→3. git add + commit→4. git push→5. Pull Request→6. review & merge→7. git pull di main
