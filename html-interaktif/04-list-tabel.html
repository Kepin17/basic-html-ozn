4 · List & Tabel

List untuk rangkaian item; tabel untuk data berdimensi baris dan kolom. Jangan memakai tabel untuk tata letak: itu tugas CSS.

TagDipakai untuk
ul + liDaftar tak berurutan (bullet)
ol + liDaftar berurutan (langkah, peringkat). Atribut start, reversed, type
dl + dt + ddIstilah dan penjelasannya
list bersarangul di dalam li (bukan langsung di dalam ul)
table, captionTabel dan judulnya
thead, tbody, tfootKepala, isi, kaki tabel
tr, th, tdBaris, sel judul, sel data
colspan, rowspanSel menjangkau beberapa kolom / baris
th scope="col"Menjelaskan arah judul untuk pembaca layar

Tantangan

  1. Satu ul (≥ 3 li) dan satu ol (≥ 3 li).
  2. Satu list bersarang: ul di dalam li dari list lain.
  3. Satu dl dengan minimal 2 pasang dt/dd.
  4. Tabel dengan caption, thead (th ber-scope="col"), tbody (≥ 3 baris), dan satu sel ber-colspan="2" (misal baris "Total").
