1 · Pengenalan JavaScript

HTML = struktur, CSS = tampilan, JavaScript = perilaku. Dengan JS, halaman bisa bereaksi: menghitung, memeriksa isian, menampilkan data, dan berubah saat diklik.

Tiga cara memasang JavaScript

<!-- 1. Inline (hindari, sulit dirawat) -->
<button onclick="alert('Halo')">Klik</button>

<!-- 2. Internal: di dalam tag script -->
<script>
  console.log("Halo dari internal");
</script>

<!-- 3. Eksternal (paling rapi): file terpisah -->
<script src="app.js" defer></script>
Atribut defer membuat skrip baru jalan setelah HTML selesai dimuat, sehingga elemen sudah ada saat kodenya mencarinya.

Alat paling penting: console.log()

Mencetak nilai ke console untuk melihat apa yang terjadi di dalam kodemu. Di browser sungguhan, buka dengan F12 → tab Console.

Aturan dasarContoh
Komentar satu baris// catatan
Komentar banyak baris/* catatan panjang */
Titik koma di akhir pernyataanconsole.log("a"); (disarankan konsisten)
Huruf besar-kecil dibedakannama ≠ Nama
