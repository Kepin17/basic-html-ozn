3 · Operator & Kondisi

Operator menghitung dan membandingkan. Kondisi membuat program memilih jalan: kalau begini lakukan itu, kalau tidak lakukan yang lain.

Operator

JenisOperatorCatatan
Aritmetika+ - * / % **% = sisa bagi, ** = pangkat
Penugasan= += -= *= ++ --x += 5 sama dengan x = x + 5
Perbandingan< > <= >= === !==Hasilnya true / false
Logika&& || !DAN, ATAU, BUKAN
Nullish??Nilai cadangan hanya bila null/undefined
== vs ===: == membandingkan setelah mengubah tipe (5 == "5" → true). === membandingkan nilai dan tipe (5 === "5" → false). Selalu pakai ===.
