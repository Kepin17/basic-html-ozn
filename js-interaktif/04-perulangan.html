4 · Perulangan

Komputer hebat dalam mengulang. Perulangan menjalankan blok kode berkali-kali tanpa kamu menulisnya berkali-kali.

Jenis perulangan

BentukDipakai ketika
for (mulai; syarat; langkah)Jumlah pengulangan diketahui
while (syarat)Ulangi selama syarat benar, jumlahnya tak pasti
for (const x of daftar)Menelusuri isi array / string
break / continueBerhenti total / lompat ke putaran berikutnya
 
for (let i = 0; i < 3; i++) {
//    ① mulai  ② syarat  ③ langkah (jalan setelah tiap putaran)
  console.log(i);          // 0, 1, 2
}
Perulangan tak berujung: lupa mengubah variabel syarat membuat while berjalan selamanya. Di lab ini pengaman akan menghentikannya, tapi di browser nyata tab bisa macet.

Lab C · Tantangan

  1. jumlah(n): jumlah 1 + 2 + … + n. jumlah(10) = 55.
  2. faktorial(n): n × (n-1) × … × 1. faktorial(5) = 120.
  3. fizzBuzz(n): kembalikan "FizzBuzz" bila habis dibagi 3 dan 5, "Fizz" bila habis dibagi 3, "Buzz" bila habis dibagi 5, selain itu angkanya sendiri.
  4. hitungVokal(teks): banyak huruf a, i, u, e, o (tak peduli besar/kecil). "Belajar JavaScript" → 6.
