5 · Fungsi

Fungsi adalah blok kode yang diberi nama supaya bisa dipakai ulang. Prinsip DRY: Don't Repeat Yourself.

Tiga cara menulis fungsi

function tambah(a, b) { return a + b; }          // deklarasi
const kurang = function (a, b) { return a - b; }; // ekspresi
const kali = (a, b) => a * b;                    // arrow function (ringkas)
IstilahArti
ParameterVariabel di definisi: function f(a, b)
ArgumenNilai saat memanggil: f(2, 3)
returnMengeluarkan hasil dan menghentikan fungsi. Tanpa return → undefined
Default parameterfunction sapa(nama = "Tamu")
Rest parameterfunction f(...angka) mengumpulkan sisa argumen jadi array

Scope (jangkauan variabel)

Variabel yang dibuat di dalam fungsi (let/const) hanya hidup di dalam fungsi itu. Variabel di luar bisa dibaca dari dalam, tidak sebaliknya.

Fungsi sebagai nilai

Di JavaScript fungsi adalah nilai biasa: bisa disimpan di variabel, dikirim sebagai argumen (callback), atau dikembalikan dari fungsi lain (closure: fungsi yang "mengingat" variabel tempat ia dibuat).

Lab C · Tantangan
