6 · Array & Object

Array = daftar berurutan. Object = kumpulan data berlabel (pasangan kunci–nilai). Hampir semua data nyata adalah gabungan keduanya.

Array

MethodFungsiMengubah array asli?
push(x) / pop()Tambah / ambil di akhir✅ ya
unshift(x) / shift()Tambah / ambil di awal✅ ya
map(fn)Ubah tiap elemen → array baru❌ tidak
filter(fn)Ambil yang lolos syarat❌ tidak
find(fn)Elemen pertama yang cocok❌ tidak
reduce(fn, awal)Menggabungkan jadi satu nilai (total)❌ tidak
includes(x), indexOf(x)Cari elemen❌ tidak
sort(), reverse()Urutkan / balik✅ ya
Indeks dimulai dari 0. arr[0] elemen pertama, arr[arr.length - 1] terakhir.

Object

const siswa = { nama: "Ani", umur: 16, hobi: ["baca", "renang"] };
siswa.nama           // "Ani"       (notasi titik)
siswa["umur"]        // 16          (notasi kurung, boleh pakai variabel)
siswa.kelas = "XI";  // menambah properti
const { nama, umur } = siswa;   // destructuring: ambil beberapa properti sekaligus
const salinan = { ...siswa, umur: 17 };   // spread: salin lalu timpa

Lab C · Tantangan

  1. rataRata(arr): rata-rata angka. rataRata([2, 4, 6]) = 4.
  2. genapSaja(arr): array baru berisi angka genap saja (pakai filter).
  3. totalHarga(keranjang): jumlah harga × jumlah dari array object (pakai reduce).
  4. namaTermurah(produk): nama produk dengan harga terendah.
