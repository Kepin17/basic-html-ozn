7 · DOM: Memilih & Mengubah

DOM (Document Object Model) adalah cara browser menyajikan halaman HTML sebagai pohon objek yang bisa dibaca dan diubah oleh JavaScript.

Dari HTML ke pohon DOM

<body>                         document
  <h1 id="judul">Halo</h1>     └─ body
  <ul>                               ├─ h1#judul  → "Halo"
    <li>Apel</li>                   └─ ul
  </ul>                                   └─ li → "Apel"
</body>

Setiap tag menjadi node/elemen. JavaScript memilih elemen, lalu mengubah isi, gaya, atau atributnya. Kotak "Pohon DOM" di lab menampilkan pohon ini secara live.

Memilih elemen

CaraMengembalikan
document.querySelector("css-selector")Elemen pertama yang cocok (atau null)
document.querySelectorAll("css-selector")Semua yang cocok (NodeList, bisa forEach)
document.getElementById("id")Elemen ber-id itu
Selector-nya sama persis dengan CSS: #id, .kelas, ul li, p:first-child. Coba di lab di bawah.

Lab A · Penjelajah selector

Ketik selector di kotak "Coba selector". Elemen yang cocok langsung tersorot oranye.

Mengubah elemen

Properti / methodFungsi
el.textContent = "..."Ganti teks (aman, tidak menafsirkan HTML)
el.innerHTML = "<b>...</b>"Ganti isi sebagai HTML. ⚠ jangan pakai data dari pengguna
el.style.color = "red"Gaya inline (properti CSS ditulis camelCase: fontSize, backgroundColor)
el.classList.add / remove / toggle / containsMengatur class (cara terbaik mengubah tampilan)
el.setAttribute("href", "..."), el.getAttribute()Atribut HTML
el.dataset.namaMembaca atribut data-nama
Lebih baik mengganti class (classList) daripada menulis banyak style langsung: CSS tetap di file CSS, JS hanya mengatur keadaan.
