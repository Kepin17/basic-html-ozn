8 · DOM: Membuat & Menghapus Elemen

Halaman nyata jarang statis: daftar produk, komentar, dan notifikasi dibuat oleh JavaScript dari data. Inilah teknik dasarnya.

Tiga langkah membuat elemen

const li = document.createElement("li");   // 1. buat (belum tampil)
li.textContent = "Item baru";               // 2. isi / atur
daftar.appendChild(li);                      // 3. pasang ke halaman (baru tampil)
MethodFungsi
createElement("tag")Membuat elemen baru di memori
parent.append(a, b) / appendChild(a)Menambah di akhir (append bisa banyak sekaligus)
parent.prepend(a)Menambah di awal
el.remove()Menghapus elemen itu
parent.replaceChildren()Mengosongkan semua isi (atau menggantinya)
el.closest("selector")Naik ke leluhur terdekat yang cocok (berguna saat menghapus kartu dari tombolnya)
el.insertAdjacentHTML("beforeend", "<li>..</li>")Menyisipkan HTML string (cepat, tapi hati-hati dengan data pengguna)
Elemen yang sudah dibuat tapi belum di-append tidak muncul. Lupa langkah 3 adalah kesalahan paling sering.

Lab B · Tantangan: kartu produk dengan tombol hapus

Dari array produk, buat satu kartu per produk di dalam #produk dengan struktur:

<div class="kartu">
  <h3>Kopi</h3>
  <p>Rp 15000</p>
  <button class="hapus">Hapus</button>
</div>

Tombol Hapus harus menghapus kartunya sendiri (closest(".kartu").remove()).
