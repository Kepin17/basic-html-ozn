9 · Event

Event adalah "kejadian" di halaman: klik, ketik, kirim form, gerakkan mouse. Dengan event listener, kodemu bereaksi saat kejadian itu terjadi. Inilah yang membuat halaman terasa hidup.

Pola dasar

elemen.addEventListener("jenis-event", function (event) {
  // kode yang jalan saat event terjadi
});
EventTerjadi saat
clickElemen diklik
inputIsi kolom isian berubah (tiap ketukan)
changeNilai select/checkbox berubah / input selesai diedit
submitForm dikirim
keydownTombol keyboard ditekan
mouseover / mouseoutKursor masuk / keluar

Objek event

  • event.target: elemen yang memicu event.
  • event.preventDefault(): batalkan perilaku bawaan (mis. form memuat ulang halaman, link berpindah).
  • event.key: tombol yang ditekan (untuk keydown).
  • input.value: isi saat ini dari kolom isian.

Lab A · Penghitung

Klik tombol-tombol di hasil. Lihat angkanya berubah, dan variabel hitungan di inspektur. Tambahkan tombol "-1" sendiri.

Lab B · Input langsung & keyboard

Ketik di kolom: tulisan "Halo" ikut berubah setiap ketukan. Tekan Enter untuk memicu event lain.

Event delegation

Memasang listener ke setiap item boros, dan item yang ditambahkan nanti tidak punya listener. Solusi: pasang satu listener di induknya, lalu periksa event.target. Event "menggelembung" (bubbling) dari anak ke induk.

daftar.addEventListener("click", (e) => {
  if (e.target.matches("li")) {       // apakah yang diklik sebuah li?
    e.target.classList.toggle("selesai");
  }
});

Lab C · Tantangan: delegation

Buat satu listener pada #daftar sehingga mengklik li mana pun menambah/menghapus class selesai (toggle). Item yang ditambahkan belakangan juga harus bekerja tanpa listener tambahan.
