10 · Proyek: Aplikasi To-do

Saatnya menggabungkan semuanya: variabel, fungsi, kondisi, array, DOM, dan event menjadi satu aplikasi kecil yang benar-benar bisa dipakai.

Spesifikasi

  1. Mengirim form (submit) menambah tugas ke #daftar. Gunakan preventDefault().
  2. Teks kosong atau hanya spasi tidak boleh ditambahkan.
  3. Setelah menambah, kolom isian dikosongkan.
  4. Tiap tugas berbentuk <li><span class="teks">…</span><button class="hapus">✕</button></li>.
  5. Mengklik .teks menandai selesai (toggle class selesai pada li-nya).
  6. Mengklik .hapus menghapus tugas.
  7. #sisa selalu menampilkan jumlah tugas yang belum selesai.
Strategi: kerjakan satu per satu dan perhatikan centang di bawah. Pakai satu listener pada #daftar untuk klik (delegation), dan satu fungsi hitungSisa() yang dipanggil setiap ada perubahan.

Pengembangan lanjutan (di luar lab)

  • Simpan tugas ke localStorage agar tidak hilang saat halaman dimuat ulang. (Tidak bisa di lab ini karena berjalan di iframe terisolasi, tapi bisa di file HTML-mu sendiri.)
  • Tambah tombol filter: Semua / Aktif / Selesai.
  • Edit teks tugas dengan klik dua kali (dblclick).
  • Simpan data sebagai array object [{ teks, selesai }], lalu render ulang daftar dari array setiap ada perubahan.
