JavaScript Interaktif

Dari nol sampai bisa membuat halaman web yang hidup: variabel, logika, fungsi, array, dan DOM. Semua kode bisa kamu ketik dan jalankan langsung di halaman.

Prasyarat: paham HTML dasar dan sedikit CSS. Kalau belum, mulai dari HTML Interaktif dan CSS Interaktif.

Cara memakai

  1. Baca penjelasan singkat, lalu lihat kode contoh di editor.
  2. Tekan ▶ Jalankan (atau Ctrl+Enter). Output tampil di Console.
  3. Ubah kodenya dan jalankan lagi. Salah itu wajar: pesan error muncul lengkap dengan nomor baris.
  4. Inspektur variabel menunjukkan isi dan tipe tiap variabel. Pohon DOM menunjukkan struktur halaman yang berubah secara live.
  5. Lab bertanda tantangan punya pemeriksa otomatis. Centangnya hijau bila kodemu benar. Tombol 💡 Lihat solusi tersedia bila macet.
Kodemu berjalan di iframe terisolasi. Aman dicoba: perulangan tak berujung dihentikan otomatis, dan tidak ada yang merusak halaman ini.
