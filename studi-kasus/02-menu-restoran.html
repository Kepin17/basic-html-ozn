Studi Kasus 2 · Menu Restoran

Level: ⭐ Mudah · Melatih: CSS tabel, selector, pseudo-class

📖 Cerita

Pemilik warung memberimu HTML menu yang sudah jadi, tetapi tampilannya polos. Tugasmu: mendandani tabel dengan CSS saja, tanpa menyentuh HTML.

✅ Syarat (diperiksa otomatis)

  1. border-collapse: collapse dan tabel melebar penuh (width: 100%).
  2. Sel (th, td) punya padding ≥ 8px.
  3. Baris tbody selang-seling berwarna berbeda (zebra) memakai :nth-child.
  4. Judul kolom (th) punya warna latar sendiri.
  5. Kolom harga (sel terakhir) rata kanan.
  6. Ada efek :hover pada baris.
🧭 Petunjuk bertahap (buka satu per satu, coba dulu sendiri)
  1. Zebra: tbody tr:nth-child(even) { background: ... }.
  2. Kolom terakhir: td:last-child { text-align: right; }.
  3. Hover: tbody tr:hover { ... }.
