Studi Kasus 3 · Navbar Responsif

Level: ⭐⭐ Sedang · Melatih: Flexbox, media query, hover

📖 Cerita

Toko online memerlukan menu atas yang rapi di laptop dan menumpuk ke bawah di HP. HTML sudah ada, kamu menulis CSS-nya.

✅ Syarat (diperiksa otomatis)

  1. Layar lebar (800px): .bar berupa flex, logo di kiri dan menu di kanan (justify-content: space-between), sejajar tengah vertikal.
  2. .menu tanpa bullet (list-style: none), berjajar menyamping (flex row), dan link tanpa garis bawah dengan padding ≥ 8px.
  3. .bar berlatar warna (bukan transparan); logo tebal (font-weight ≥ 600).
  4. Link berubah saat :hover.
  5. Layar sempit (400px): menu menumpuk ke bawah (flex-direction: column pada .menu atau .bar) lewat @media.
🧭 Petunjuk bertahap (buka satu per satu, coba dulu sendiri)
  1. Mulai dari .bar { display: flex; ... } lalu .menu { display: flex; list-style: none; }.
  2. Reset margin dan padding pada ul.
  3. Tambahkan @media (max-width: 600px) { .menu { flex-direction: column; } }.
