Studi Kasus 4 · Kartu Harga

Level: ⭐⭐ Sedang · Melatih: CSS Grid, responsif, hover, hierarki visual

📖 Cerita

Halaman harga yang bagus menonjolkan paket andalan. Kamu merancang tiga kartu: tiga kolom di laptop, satu kolom di HP, dan paket "Pro" harus paling menarik.

✅ Syarat (diperiksa otomatis)

  1. .daftar memakai display: grid dengan 3 kolom di layar 800px dan gap > 0.
  2. Di layar 500px menjadi 1 kolom (media query).
  3. .paket: padding ≥ 16px, border-radius ≥ 8px, box-shadow, teks rata tengah.
  4. .populer tampil berbeda: warna latar atau border atau transform berbeda dari paket biasa.
  5. .btn berlatar warna, teks kontras, tanpa garis bawah.
  6. Kartu punya efek :hover.
🧭 Petunjuk bertahap (buka satu per satu, coba dulu sendiri)
  1. grid-template-columns: repeat(3, 1fr).
  2. Bedakan paket populer: .populer { border: 2px solid #2563eb; transform: scale(1.04); }.
  3. Satu kolom di HP: @media (max-width: 600px) { .daftar { grid-template-columns: 1fr; } }.
