Studi Kasus 5 · Kalkulator Tip

Level: ⭐⭐ Sedang · Melatih: Memisahkan logika dari tampilan, validasi, pembulatan

📖 Cerita

Kamu dan teman makan bersama dan ingin membagi tagihan plus tip. Prinsip penting: tulis fungsi murni hitungTip (mudah diuji), lalu sambungkan ke tampilan.

✅ Syarat (diperiksa otomatis)

  1. hitungTip(tagihan, persen, orang) mengembalikan { tip, total, perOrang }, semuanya dibulatkan ke bilangan bulat (Math.round).
  2. Input tidak valid (tagihan ≤ 0, orang < 1, atau bukan angka) → mengembalikan null.
  3. Tombol Hitung membaca #tagihan, #persen, #orang lalu mengisi #tip, #total, #perorang.
  4. Bila input tidak valid, ketiga hasil kembali menjadi -.
🧭 Petunjuk bertahap (buka satu per satu, coba dulu sendiri)
  1. Hitung dulu di kertas: 250.000 + tip 20% = ? dibagi 5 orang = ?
  2. Pecah masalah: (1) validasi, (2) hitung tip, (3) hitung total, (4) bagi per orang.
  3. Mengambil nilai input selalu berupa string; ubah dengan Number().
