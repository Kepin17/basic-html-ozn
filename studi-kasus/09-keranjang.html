Studi Kasus 9 · Logika Keranjang Belanja

Level: ⭐⭐⭐ Menantang · Melatih: Array of object, immutability, reduce, aturan bisnis

📖 Cerita

Inti setiap toko online adalah logika keranjang. Kamu menulis fungsi-fungsinya tanpa mengubah array asli (immutable), kebiasaan yang membuat bug berkurang drastis.

✅ Syarat (diperiksa otomatis)

  1. Item keranjang berbentuk { id, nama, harga, qty } (data dari array produk).
  2. tambahKeranjang(keranjang, id) mengembalikan array baru: qty +1 bila sudah ada, atau item baru ber-qty 1. ID tak dikenal → isi tidak berubah. Array asli tidak boleh berubah.
  3. hapusItem(keranjang, id) mengurangi qty satu; bila jadi 0, item dibuang. Array baru.
  4. totalKeranjang(keranjang) = jumlah harga × qty.
  5. hitungDiskon(total): total ≥ 500.000 → 10%; ≥ 200.000 → 5%; selain itu 0. Hasil berupa jumlah diskon (dibulatkan).
🧭 Petunjuk bertahap (buka satu per satu, coba dulu sendiri)
  1. Hindari push/splice. Pakai map, filter, dan spread [...arr, item] yang menghasilkan array baru.
  2. Untuk "naik 1 qty" tanpa mengubah objek lama: { ...x, qty: x.qty + 1 }.
  3. Uji di console: const a = tambahKeranjang([], 1) lalu cek a dan [].
