Studi Kasus 11 · Proyek Akhir: Landing Page Webinar

Level: ⭐⭐⭐⭐ Sulit · Melatih: HTML + CSS + JavaScript sekaligus

📖 Cerita

Proyek penutup yang menggabungkan semuanya. HTML sudah disediakan (semantik, lengkap dengan id). Kamu menulis CSS (tata letak responsif) dan JavaScript (validasi form) sampai semua centang hijau. Pindah antar tab CSS dan JavaScript di editor.

✅ Syarat (diperiksa otomatis)

  1. CSS: .manfaat berupa grid 3 kolom (layar 800px) dan 1 kolom (layar 400px, media query).
  2. CSS: .kartu ber-padding ≥ 16px dan border-radius ≥ 8px. Pesan .galat berwarna merah.
  3. JS: saat form dikirim, preventDefault(); nama minimal 2 karakter (setelah trim) dan email berformat valid. Kesalahan ditulis di #err-nama / #err-email; kolom yang benar → pesan kosong.
  4. JS: bila semua valid → sembunyikan form, tampilkan #sukses berisi nama pendaftar.
  5. JS: bila ada yang salah → #sukses tetap tersembunyi dan form tetap tampil.
🧭 Petunjuk bertahap (buka satu per satu, coba dulu sendiri)
  1. Kerjakan per lapisan: CSS dulu (hasilnya langsung terlihat), lalu JavaScript.
  2. Untuk menyembunyikan elemen, atribut hidden cukup: el.hidden = true.
  3. Regex email sederhana: /^[^\s@]+@[^\s@]+\.[^\s@]+$/.
